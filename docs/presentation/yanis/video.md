# Séquence vidéo Yanis

Un support commenté avec voix de synthèse française accompagne cette livraison. Il présente les slides
actualisées et les captures réelles des chargements manuels du 3 novembre. Il ne simule pas un nouveau run
et ne constitue pas un enregistrement interactif d'Airflow. Le fichier MP4 est dans ce dossier.
Le texte prononcé est dans `narration_video.json`.

Pour enregistrer une version avec la voix de Yanis, reprendre le même déroulé :

1. Présenter le cas métier B2C, les hypothèses de revenus et les dix artistes.
2. Montrer les trois sources et les volumes des deux semaines.
3. Expliquer API → GCS → COPY INTO → BRONZE avec les quatre colonnes de traçabilité.
4. Montrer `docs/evidence/2026-11-03_bronze_deux_semaines_run1.jpg`, puis la capture `rejeu.jpg`.
5. Lire les trois volumes, zéro doublon et les empreintes identiques. Les captures datent du 3 novembre.
6. Mentionner le run d'équipe documenté et transmettre la parole à Hugo pour dbt et Dash.

La vidéo globale du run Airflow appartient à la partie Elimane. L'assemblage final nécessite les séquences
des autres membres. Le profil CSV Yanis ne doit être annoncé dans Dash qu'après validation de son intégration.
Ne pas filmer les credentials, fichiers `.env`, clés ou détails de connexion.
